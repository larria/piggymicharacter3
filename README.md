# 咪猪头识字探险岛

原创 React + TypeScript + Vite 单设备本地汉字学习应用。奶油白、青绿海岛与暖珊瑚配色，原创 CSS 与 SVG 小猪化身/岛屿；未复制旧项目代码、界面或背景。

## 启动与验证

```sh
npm install
npm run dev
npm test
npm run build
npx vite preview --host 0.0.0.0 --port 4173
```

开发地址由 Vite 输出，默认 http://localhost:5173。离线/PWA 请使用生产构建预览或 HTTPS 部署，开发服务器不会注册 Service Worker。

## 功能与机制

- 今日探险：到期/逾期优先、新字额度、认识字两道不同的无提示视觉识别题、精简教学、点击朗读/停止、可暂停恢复。
- 跨天复习：首次有效验证后次日再见；之后 3、7、14、30 天，稳定后持续每 30 天复习。每字每天最多推进一次，提示答对/同日重复/纠错不晋级。使用本地日历与可注入日期；时钟回拨不会倒退记录日期。
- 答错回补：退一级，明日再次复习；至少穿插两个其他字任务才加入纠错，否则留到后续。纠错答对不取消明日任务。
- 奖励：同日每字最多 1 贝壳，每日完成最多 3 贝壳；卡片目录动态（当前 60 张），每张 10 贝壳，预览/大图/幂等兑换，不透支。
- 地图/图鉴：真实里程碑、汉字/拼音/词搜索、状态过滤、详情与到期日期。识字状态不意味着已验证独立朗读能力。
- 每日安排上限、本周真实印章、连续学习日；不要求凑满安排，缺席不扣资产。
- 爸爸空间确认（动态初高中数学知识题，整数答案大于 10）：节奏、音效、背景音乐、近期真实记录、JSON 导出/导入。确认门仅防误触，不是身份认证。

咪猪头是孩子本人，小猪是她在探险岛的小猪化身，不是另一个陪伴角色。页面中的大猪头话语是固定署名的爸爸寄语，不是爸爸实时在线或实时评价；肯定认真尝试，期待真实学会的本领，不以成绩条件化爱。卡片保持编号，不猜测家庭身份，也不强制命名。

爸爸解锁后可搜索汉字、拼音和词语，选择最多 10 个字直接双题验证；目前仅 17 字支持独立识别验证，其他字明确作为读音提示辅助练习，不计独立掌握；进行中的会话不能被选字会话替换。首页展示实际保留任务的剩余字数与题数（新字直接验证可能追加题目），不以设置额度冒充实际安排。教学首屏保留 1–2 个词和 1 句，更多例子收进可展开区域。

## 数据与存储

存储键 `mizhupig.expedition.v1`，localStorage 中版本化保存进度、任务、设置、日志、奖励账本、收藏。提交与兑换采用幂等标识；修订号防止旧标签页覆盖新数据，并监听跨标签页更新。浏览器禁止存储、空间不足或异常数据会明确报错，不静默覆盖。localStorage 不是数据库事务系统；请勿同时在多个标签页进行操作。

导出 JSON 是用户可控的备份，包含实际学习记录；导入校验版本、设置范围、字库 ID、日期、唯一记录、任务结构。恢复替换当前数据前需要确认。清理浏览器数据、隐私模式结束、换设备不会自动恢复，请定期备份。没有账号或云同步，也不迁移旧版掌握状态；旧记录缺少跨天证据。

## 批量导入奖励卡片

先将新图片放入独立的临时目录，再运行（目录必须为绝对路径）：

```sh
npm run cards:import -- /absolute/temp --dry-run
npm run cards:import -- /absolute/temp
# 手动删除不再需要的卡片后，仅重新生成清单，不导入任何图片：
npm run cards:import -- --sync
# 等价快捷命令：
npm run cards:sync
npm run test:cards
```

支持 jpg、jpeg、png、webp、avif、tif、tiff（不区分扩展名大小写）；只读取目录第一层的普通文件，忽略其他扩展名、子目录和符号链接。文件名按确定的字典顺序导入，每张图片分配当前最小的空缺非负 ID，输出 `cN.jpg`。已有卡片的文件名、ID 和内容保持不变，绝不覆盖已有目标，也不删除源文件。不要把现有卡片目录作为导入源，否则会将其作为新的卡片再次导入。

Sharp 自动纠正 EXIF 方向、将透明区域合成白色、保持比例将最长边限制为 1600 像素（不放大小图），最后以质量 82 编码为 JPEG，并移除原始元数据。全部图片先在临时目录中成功转换才发布；任何损坏或无效的支持格式图片使整个批次失败，不留下部分导入。发布失败时回滚本批新建文件和已更新的清单，不删除原有图片。操作期间请勿并发导入或手动修改目标目录；两个清单文件的更新不是跨文件系统的数据库事务，进程被强制终止后可运行 `--sync` 重建清单。

`--dry-run` 仍实际解码和转换，以检查错误并报告准确体积，但不写入目标目录或清单。命令报告导入数、已有数、总数、输入/输出字节数及节省比例（小图可能增大，因此节省值可为负）。`--sync` 不接受源目录，也不删除任何资产；它扫描磁盘上现有的 `cN` 图片，保留文件名并移除清单中已被人工删除的条目。重复数字 ID（如同时存在 `c1.jpg` 与 `c01.png`）会报错，需人工解决。

每次成功导入或同步会生成内容一致、按数字 ID 排序的 `public/cards/manifest.json` 和 `src/data/cards.json`。清单是纯数组，例如 `[{"id":0,"file":"c0.jpg"}]`，不包含源路径或其他私人元数据。导入后重新运行 `npm run build` 并部署，以更新应用及离线资源；已发布的应用不会自动获取本地新文件。`scripts/import-cards.node-test.mjs` 使用独立临时目录覆盖空缺编号、格式、方向/尺寸/透明度、无效输入、失败回滚、预演和删除后同步，不触碰项目原有卡片。加载或恢复备份只能移除当前目录中不存在的卡片 ID。收藏记录仅保存数字 ID；如果删除后复用同号，而旧收藏未在该 ID 缺席时被清理，应用无法区分旧卡与新卡，旧收藏可能显示为新卡。这里不做卡片身份迁移，也不保证删卡重用 ID 自动清除旧收藏。

## 离线与语音限制

生产 Service Worker 缓存应用入口、构建资源、卡片清单中的全部卡片及音频；完整安装成功后才显示缓存提示。首次使用需联网，缓存可能被浏览器回收，不能保证永久离线。新版本 Service Worker 按浏览器默认生命周期等待旧页面关闭，不在任务中强制更新。安装能力取决于浏览器，HTTPS 或 localhost 才支持 Service Worker。

设备朗读使用浏览器 `speechSynthesis`，只在点击后触发；设备无中文声音或离线语音时允许继续看题，显示失败提示。题目采用结构化整字/整词遮罩，朗读直接使用遮罩片段，不再次拆分目标汉字。缺少可用例句的回退明确显示读音提示；它是辅助练习，不会作为无提示掌握证据或推进间隔。听音识别不等于独立朗读。音效和背景音乐亦只由用户操作启动，暂停/离开页面取消朗读与音乐。自动测试不能验证每台设备真实发声。

## 结构

- `src/domain.ts`：纯调度、题目、会话、奖励函数与注入日期
- `src/storage.ts`：版本存储、备份验证、修订冲突
- `src/data/catalog.ts`：授权字库归一化
- `src/App.tsx`：四入口、完整学习交互、详情/家长/备份
- `src/Art.tsx`、`src/style.css`：原创艺术与响应式视觉
- `public/sw.js`、`manifest.webmanifest`：生产离线/PWA
- `tests/domain.test.ts`：学习/跨午夜/回拨/纠错/奖励/恢复等机制

无初始模拟进度、付费、广告、排行榜或虚构在线活动。首版不提供账号、服务端同步或独立朗读评测。
