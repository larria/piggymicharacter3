# 咪猪头识字成长册

面向孩子的单设备本地汉字学习应用，使用 React、TypeScript 与 Vite 构建。通过识字探险、跨天复习、原创猪头段位和收藏墙，记录真实学习与成长；没有账号、云同步、广告或付费功能。

## 快速启动

```sh
npm install
npm run dev
```

开发地址以 Vite 输出为准，默认 http://localhost:5173。

```sh
# 自动化测试与生产构建
npm test
npm run build
# 预览生产构建
npx vite preview --host 0.0.0.0 --port 4173
# 部署到 GitHub Pages（自动先构建，发布 dist/ 到 gh-pages 分支）
npm run deploy
```

线上地址：https://larria.github.io/piggymicharacter3/

## 版本、图标与安全更新

首页显示版本自动来自 `package.json.version`，不单独修改界面字符串；同版本代码更新通过构建内容 hash 识别。点击版本入口检查／应用更新，不清除本机学习数据；学习、考试、导入、保存冲突或同 scope 其他窗口打开时不会强制刷新。

图标原图保留在非公开 `assets/icon-source/piggy-original.png`，用 `node scripts/generate-icons.mjs` 重建四种优化 PNG。生产 A/B 本地验证使用 `scripts/pwa-ab-fixture.mjs`，运行与同源切换步骤见开发规格；此脚本不发布、不提交、不清浏览器存储。

## 默认安排与朗读失败恢复

新用户默认每日安排 **5 字**、新字上限 **5 字**（5/5）；已有合法设置与进行中的任务不因默认值调整而覆盖。

朗读失败后的恢复等待为 10 秒，不是播放中的语音超时。`NarrationWait.start(valid, release, onTick?)` 保留原来的双参数调用方式；可选 `onTick(secondsRemaining)` 立即报告 10，此后每秒报告 9 至 0，等待结束且任务仍有效时才释放。取消、重试替换和任务失效会停止旧倒计时，避免旧任务释放；回调中取消或失效也会阻止最终释放。

每字基础两题，新字先听读与跟写；辅助验证或答错可能补学。进入跟写先保存阶段，暂停与刷新恢复累计时间，不保存墨迹。总静音不覆盖音效、音乐的独立偏好，也不影响设备朗读。收藏兑换确认显示卡号与缩略图，切换标签取消确认；余额不足可返回练习。

加载异常时禁止把空占位进度保存或导出为完整备份；“原始救援数据”只读保留存储原文及逐项读取错误，不是可直接导入的标准备份，也不包含未保存墙草稿。冲突／未保存墙草稿刷新前需明确确认；完成页可恢复历史待到账奖励，不重复发奖。
